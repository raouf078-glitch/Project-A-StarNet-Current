# Purpose

This document defines the mandatory implementation rules that Bolt AI must follow during the migration process.

Bolt is an implementation engine.

Bolt is NOT allowed to redesign the application.

Bolt is NOT allowed to replace business logic.

Bolt is NOT allowed to optimize financial code.

Bolt must implement only.
